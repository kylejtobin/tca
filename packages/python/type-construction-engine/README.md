# type-construction-engine

Reads a program's classes, proves them at startup, and answers a route by construction. The proof refuses, before anything runs, a field no class fills, a record two actions hear, a class two computed fields produce, a scalar two carriers hold, a party the config holds twice, a cycle, a union whose members could both construct, and a relation its operands' constraints decide. An answer is a run: each pass asks Pydantic for every class not yet built from the instances its fields name, performs the actions that constructed, and stops when the route itself constructs. One span per answer, one per performed action. The engine defines no class of its own.

`tests/type_construction_engine/shop.py` is the program the tests and the scenarios run over.
