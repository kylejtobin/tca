# type-construction-world

The kinds a developer writes an application with. Ten Pydantic classes say what a thing is: `Scalar`, `Setting`, `Value`, `Request`, `Record`, `Fact`, `Action`, `Reply`, `Connection`, `Route`, and `Config` holds the deployment. Thirteen more say a computation without an expression: `Times` and `Sum` derive a value, computed at construction by the operation each declares; `Under`, `AtMost`, `Equal`, `AtLeast`, `Beyond`, `Differs` and `Between` relate values, each the one comparison restricted to the orderings its `Literal` admits, and refuse when the ordering is not admitted; `Least`, `Greatest`, `First` and `Only` choose among elements, by the shape of their tuple, and refuse when there is nothing to choose. Each kind declares its meaning once, as Pydantic reads it, and the engine's proof reads the same declaration. A constant is a scalar with a default root; `Instant` and `Identity` are fresh scalars; `Duration` is a positive `timedelta`. Every class is strict, frozen, and refuses what it does not declare.
