# Govern Next

The plan was written before the last task existed. Choose the next step from
what is known now, toward the overall outcome stated in measure-outcome.
Write three lines, in this order:

```
Best:    the step Learned points to, and which part of Learned points there.
Planned: the step the plan says is next.
Do:      Best. If Planned differs, one clause on why the plan lost.
```

## Gotchas

- You will set Best equal to Planned without deriving it. That is why Best
  comes first and must cite Learned. If nothing in Learned would have changed
  it, say so; that is a finding about Learned.
- You will defend a step because it was planned. A step defended for having
  been planned is serving the plan, not the outcome.
- You will treat the plan as the unit of work. Deleting the next step is a
  step. Deleting the plan is a step.
