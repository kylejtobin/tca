# OKF Skill Authoring

This directory is itself an OKF skill. Copy its shape.

- [open-knowledge-format.md](open-knowledge-format.md): What OKF is, and which parts of the spec a skill keeps. Read first when the format is unfamiliar or when a spec detail is in question.
- [skill-anatomy.md](skill-anatomy.md): The directory layout and the SKILL.md frontmatter of an OKF skill. Read when creating a skill or checking one's structure.
- [index-body.md](index-body.md): How the SKILL.md body is written as routes to pages. Read when writing or editing any SKILL.md body.
- [pages.md](pages.md): What one page holds, its frontmatter, and its body shape. Read when adding, splitting, or rewriting a page.
- [cross-linking.md](cross-linking.md): How pages link to each other and to SKILL.md. Read when adding a link or moving a page.
- [naming.md](naming.md): How the skill directory and `name` field are chosen. Read when creating or renaming a skill.
- [skill-description.md](skill-description.md): How the `description` field is written so the skill triggers on the right requests. Read when writing or tuning a description.
