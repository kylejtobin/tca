# 0052. A class no route's reply leads to is refused at startup, as the mirror of a field no class fills

Status: accepted

## Context

A scalar nothing holds, a record a party may say that no conclusion holds, an action whose answer nothing uses, a connection no action is toward: each was constructed, performed or opened without a fault, and an effect could be performed for a reply that was never made from it. The run constructs by supply, every class whose premises are present, so the proof is what makes supply equal demand.

## Rejected

A walk from each route through what brings each class, kept as a map: a second representation of what the fields already say. Exempting base classes by reading `__mro__`: a judgment about which classes count, not a read of fields. `used(cls)`, true when some field of some declared class named the class: one step of reachability from anywhere, so two classes that held each other were used, and a class no reply led to was used by a class no reply led to.

## Decision

`Proof.reached(start)` is the closure from a class through its fields, the words of its computed fields, the carriers of what it holds, the declarers of an element and the hearer of a record, and so on from each. A class not in the closure of any route is refused as `unreached`, "X is reached by no route; hold it or delete it"; a `Config` and the settings the deployment holds are the deployment's and are exempt. The same closure is what a route's run asks for, `Proof.built(route)`: the reached classes that are not scalars and have no source of their own (0050). So every class the run constructs is one the reply leads to, and the run constructs nothing the reply does not need, without computing a demand order.

## Evidence

The program with the faults, with `Stray(Scalar[str])` held by nothing: `proven` raised `unreached` at `("Stray",)`; `Collects`, held by nothing, was reported `unreached` beside its `collects` fault; `Direct`, a request no route takes, was reported `unreached` beside its `boundary` fault. In the engine's test program, `Heard` is held by no field and carries `Amount`, which `Low` holds, and `Notify` is reached through the `Noted` record `Dear` holds: `proven` passed, and `proof.built(Operation)` was `Asked`, `Portion`, `Portions`, `Largest`, `Low`, `High`, `Notify`, `Cheap`, `Dear`, `Total`, `Concluded`, `Answered` and `Operation`, with neither `Heard`, `Limit` nor the connections among them.

## Consequences

Unwritable: a fire-and-forget action, a party's answer nothing concludes from, a scalar declared and not held, a class only another unreached class leads to. Refuted by a class a program needs that no reply leads to; none found.
